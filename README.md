# Olha Yudina — Portfolio

Personal portfolio website showcasing my projects, skills, and background as a Software Engineer.

## About

Built with Next.js and Tailwind CSS, this site presents my work across frontend and backend development — from AI-powered applications to full-stack web platforms — along with the tools and technologies I use.

## Features

- **Responsive design** — clean layout that adapts from mobile to desktop
- **Light / dark theme** — toggle with system preference detection
- **Featured projects** — with live links and GitHub repos where available
- **Scroll-spy navigation** — active section highlighted in the navbar as you scroll

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** [lucide-react](https://lucide.dev/), [react-icons](https://react-icons.github.io/react-icons/)
- **Animation:** [Motion](https://motion.dev/)
